# HabitFlow - Mobile Habit Tracking Dashboard

A lightweight, modern, and mobile-optimized habit tracker dashboard built with HTML, Tailwind CSS, Lucide icons, and browser LocalStorage. 

## Features
- **Weekly Streak Tracking:** Log daily habits and visualize weekly streaks at a glance.
- **Dynamic Stats:** Track your completion rate, active streaks, and daily progress instantly.
- **Mobile-First Design:** Fully responsive dark-mode UI optimized for touchscreens and home-screen installation.
- **Data Privacy:** All data is securely stored locally on your device via browser LocalStorage.

## How to Use
1. Open the live GitHub Pages link on your phone browser.
2. Tap the browser menu (three dots or share button) and select **Add to Home Screen**.
3. Launch it directly from your home screen for a full-screen, app-like experience!
